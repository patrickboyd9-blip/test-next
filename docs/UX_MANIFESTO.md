# Modern Mail UX Manifesto

This document defines how Modern Mail should feel.

The Product Bible defines what Modern Mail is.

The PRDs define how individual features work.

The UX Manifesto defines how every interaction should feel to the customer.

Every page, workflow, animation, recommendation, and interface decision should reinforce these principles.

When making product decisions, these principles take precedence over trends, personal preferences, or visual aesthetics.

## Principle 1 — Every screen answers a question.

Customers do not open Modern Mail to look at software.

They open Modern Mail because they have a question they need answered.

Every page should answer that question within a few seconds.

Examples:

- Command Center → "Is my campaign working?"
- Campaigns → "What do I want to send?"
- Audience → "Who should I send this to?"
- AI Creator → "What should I say?"
- Insights → "What did I learn?"

If a screen cannot clearly answer the customer's primary question, it should be redesigned until it can.

## Principle 2 — Show answers before evidence.

Customers should never have to interpret charts, tables, or metrics before understanding what is happening.

Modern Mail should first answer the customer's question in plain English.

Evidence should support the answer—not replace it.

Every screen should follow this pattern:

Question

↓

Answer

↓

Evidence

↓

Recommended Action

Modern Mail interprets information so customers don't have to.

## Candidate Principles
- Every page answers a customer question.
- Show answers before evidence.
- Every page invites action before presenting information.
- AI interprets information instead of exposing raw metrics.
- Every recommendation explains why.
- Customers should never wonder what to do next.
- Reduce cognitive load whenever possible.
- Powerful enough for experts, approachable enough for beginners.
- Modern Mail should feel optimistic, never overwhelming.
- Progress should always be visible.
- Software should feel like a teammate, not a reporting tool.
- Replace complexity with confidence.
