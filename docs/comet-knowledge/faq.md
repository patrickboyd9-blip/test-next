# Common questions

What should I do next? If you are on the start screen, pick how you want to begin. If a proof is ready, open it and approve it only when it looks right. If you are choosing who receives it, pick a list.

Can Comet mail it for me? No. Comet can open the proof or the start of a mailer. You approve it yourself.

Where do I talk to a person? Ask Comet for a person. The note stays on the screen. It is not emailed from here.
