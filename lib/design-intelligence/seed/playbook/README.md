# Designer Playbook

This is the knowledge layer for Modern Mail’s art-director step. It does not lay out cards. Phase 2 reads it, emits a Design Rationale (`schemas/design-rationale.schema.json`), then composes and critiques.

Use it in this order:

1. `01-visual-principles.md` — how a card is seen.
2. `02-direct-mail.md` — what changes because the object is mail.
3. `03-verticals.md` — roofing, plumbing, HVAC, Medicare/insurance, real estate, general local service.
4. `04-how-to-critique.md` — the pass a vision critic runs before a grade.

House system this playbook extends, and does not replace:

- Principles P1–P12 in `notes/transferable-principles-draft.md`
- Checkable rules TP-01–TP-12 in `notes/principles-tight.md`
- Anti-patterns AP-001–AP-012 in `references/anti-pattern-examples.md`
- Ship gate AF1–AF10 and D1–D6 in `rubrics/A-Plus-Postcard-Rubric.md`

Labels: **[E]** is a published standard or a measurement you can take off the artboard. **[C]** is a Modern Mail house rule. House rules are defaults. Recalibrate them when response data disagrees.

Two ratios that look similar and are not:

- Offer cap-height ≥ 1.6× the headline cap-height, **when the offer is the hero**. **[C]**
- Offer size ≥ 1.5× body, and headline cap-height ≥ 2.5× body, on every card that has those elements (AF5, TP-03). **[C]**

A question-led card (the headline is the hero) may keep the offer smaller than the headline. A numeral-led card must not.
