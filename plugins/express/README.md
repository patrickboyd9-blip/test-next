# Modern Mail add-on

Design a 5×8 or 6×9 postcard, front and back, then send the print file to a Modern Mail campaign.

The page is the full print file, including 0.25 in of bleed: 8.5×5.5 in or 9.5×6.5 in. Guide marks are locked. They are taken off the page before the PDF is made, then put back.

## Try the panel on your computer

Open `plugins/express/index.html` in a browser. Create the front and the back, then check the size line.

Inside the add-on, `sandbox/code.js` creates the pages. Replace `testId` in `manifest.json` with the id from your developer console before you submit.

## What you do to publish it

1. Create a free Adobe ID, if you do not have one.
2. In the Adobe developer console, create an add-on for Express. Copy the id it gives you into `testId`.
3. Install the free add-on tools on your computer and load this folder so you can try it in Express.
4. Add a support email and a privacy note that says the token is sent only to Modern Mail to save the postcard.
5. Submit the add-on for review. Review is usually one to two weeks.

No developer account was created from this project, and the add-on was not submitted.
