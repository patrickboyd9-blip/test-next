# Modern Mail for Figma

Design a 5×8 or 6×9 postcard, front and back, then send the print file to a Modern Mail campaign.

## Try it on your computer

1. Install Figma Desktop.
2. Open a design file.
3. Go to Plugins, Development, Import plugin from manifest.
4. Choose `plugins/figma/manifest.json`.
5. Run Modern Mail from Plugins, Development.

Create an API token in Modern Mail at Settings, API & AI assistants, and paste it into the panel.

## What you do to publish it

1. Create a free Figma account and a team, if you do not have one.
2. In Figma, open the Community hub and choose to publish a plugin. Use this folder.
3. Add a support email, a short description, and a privacy note that says the token is sent only to Modern Mail to save the postcard.
4. Submit for review. Figma usually replies in a few days, and sometimes up to two weeks.
5. Do not submit until you have tried Import plugin from manifest on your own machine.

No marketplace account was created from this project.
